MARJHO PRINT SERVICE — ETAPA 3

INCLUIDO EN ESTA ENTREGA
- Buscador de servicios de impresión mDNS/DNS-SD.
- Popup con impresoras encontradas y selección directa por IP.
- IP manual y prueba de puerto TCP 9100.
- Importar PDF, DOCX, TXT, JPG, JPEG, PNG, WEBP y BMP.
- Vista previa de la primera página PDF.
- Edición de texto TXT y extracción de texto DOCX como borrador TXT.
- Rotación de imágenes y guardado PNG.
- Conversión de imagen a PDF A4.
- Envío directo ESC/P-R de PDF compatible a IP seleccionada.
- Editor de etiquetas conservado.
- Servicio PrintService Android conservado.

NO INCLUIDO TODAVÍA
- Edición del texto original dentro de PDF.
- Guardado DOCX conservando formato, tablas, imágenes y estilos.
- Editor de imágenes avanzado (recorte libre, capas, filtros).
- Negociación IPP real y lectura automática de capacidades de cada modelo.
- Controladores universales para todas las marcas.
- Confirmación de impresión física desde TCP 9100.

IMPORTANTE
La impresora encontrada por mDNS no necesariamente es compatible con el controlador ESC/P-R. El envío directo de esta versión está destinado al flujo ESC/P-R validado para Epson L4150 y requiere prueba física en la red del usuario.
